# Rubryka Z07

Wersja 1.0.0 — rocznik 2026-27

Maksimum: 10 punktów. Wagi w ocenie tej części kursu i terminy określa konfiguracja rocznika.

Kontrola techniczna sprawdza pliki i odtworzenie; dobór, interpretację i uzasadnienie ocenia osoba prowadząca. Brak istotności nie obniża punktacji.

## Z07.1 — 2 pkt

Wybór chi-kwadrat lub Fishera uzasadniony strukturą i liczebnościami.

| Punkty | Obserwowalny dowód |
|---:|---|
| 0 | Brak dowodu lub wynik nie realizuje kryterium. |
| 0.5 | Wybrano test bez kontroli tabeli. |
| 1 | Sprawdzono N, lecz pominięto liczebności oczekiwane lub niezależność. |
| 1.5 | Wybór poprawny; jedno uzasadnienie niepełne. |
| 2 | Wybór chi-kwadrat lub Fishera uzasadniony strukturą i liczebnościami. |

## Z07.2 — 3 pkt

Tabela liczebności i odsetków ma poprawne mianowniki, sumy i podpisy.

| Punkty | Obserwowalny dowód |
|---:|---|
| 0 | Brak dowodu lub wynik nie realizuje kryterium. |
| 0.75 | Fragment tabeli bez określenia mianownika. |
| 1.5 | Liczebności poprawne, lecz odsetki mają mylony mianownik. |
| 2.25 | Liczebności i odsetki właściwe; brakuje jednej etykiety. |
| 3 | Tabela liczebności i odsetków ma poprawne mianowniki, sumy i podpisy. |

## Z07.3 — 3 pkt

Test i miara związku są poprawnie obliczone oraz odczytane.

| Punkty | Obserwowalny dowód |
|---:|---|
| 0 | Brak dowodu lub wynik nie realizuje kryterium. |
| 0.75 | Próba testu bez poprawnej tabeli wejściowej. |
| 1.5 | Test poprawny; V błędne albo odczytane jako kierunek zależności. |
| 2.25 | Test i V poprawne; brakuje jednej statystyki w zapisie. |
| 3 | Test i miara związku są poprawnie obliczone oraz odczytane. |

## Z07.4 — 2 pkt

Wykres/wniosek określa kierunek wzorca i nie przypisuje przyczynowości.

| Punkty | Obserwowalny dowód |
|---:|---|
| 0 | Brak dowodu lub wynik nie realizuje kryterium. |
| 0.5 | Wniosek nie określa wzorca odsetków. |
| 1 | Wzorzec odsetków poprawny, lecz opis przypisuje przyczynowość. |
| 1.5 | Wzorzec i ostrożność poprawne; wykres ma drobną lukę opisu. |
| 2 | Wykres/wniosek określa kierunek wzorca i nie przypisuje przyczynowości. |
