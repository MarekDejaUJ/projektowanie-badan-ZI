# Rubryka Z06

Wersja 1.0.0 — rocznik 2026-27

Maksimum: 10 punktów. Wagi w ocenie tej części kursu i terminy określa konfiguracja rocznika.

Kontrola techniczna sprawdza pliki i odtworzenie; dobór, interpretację i uzasadnienie ocenia osoba prowadząca. Brak istotności nie obniża punktacji.

## Z06.1 — 3 pkt

Wybór testu uwzględnia pytanie, skalę, niezależność i projekt, z krótkim uzasadnieniem.

| Punkty | Obserwowalny dowód |
|---:|---|
| 0 | Brak dowodu lub wynik nie realizuje kryterium. |
| 0.75 | Nazwa testu bez uzasadnienia. |
| 1.5 | Skala uwzględniona; niezależność albo projekt pominięte. |
| 2.25 | Dobór pasuje do projektu; jedno założenie nieopisane. |
| 3 | Wybór testu uwzględnia pytanie, skalę, niezależność i projekt, z krótkim uzasadnieniem. |

## Z06.2 — 3 pkt

Poprawna analiza dwóch grup, opis/wykres, efekt i niepewność.

| Punkty | Obserwowalny dowód |
|---:|---|
| 0 | Brak dowodu lub wynik nie realizuje kryterium. |
| 0.75 | Obliczono test bez poprawnego opisu grup. |
| 1.5 | Test poprawny; efekt albo przedział błędny. |
| 2.25 | Opis, efekt i przedział poprawne; jeden element wykresu pominięty. |
| 3 | Poprawna analiza dwóch grup, opis/wykres, efekt i niepewność. |

## Z06.3 — 2 pkt

Statystyka, stopnie swobody tam gdzie dotyczą, p, kierunek efektu i N są raportowane poprawnie.

| Punkty | Obserwowalny dowód |
|---:|---|
| 0 | Brak dowodu lub wynik nie realizuje kryterium. |
| 0.5 | Podano p bez statystyki i N. |
| 1 | Statystyka i p poprawne; df albo kierunek efektu błędny. |
| 1.5 | Wynik poprawny; pominięto jedno N albo oznaczenie metody. |
| 2 | Statystyka, stopnie swobody tam gdzie dotyczą, p, kierunek efektu i N są raportowane poprawnie. |

## Z06.4 — 2 pkt

Interpretacja własna, zgodna z wynikiem, bez utożsamienia istotności z wagą praktyczną.

| Punkty | Obserwowalny dowód |
|---:|---|
| 0 | Brak dowodu lub wynik nie realizuje kryterium. |
| 0.5 | Wniosek ogranicza się do etykiety istotny/nieistotny. |
| 1 | Kierunek poprawny, lecz istotność utożsamiono z wagą praktyczną. |
| 1.5 | Własna interpretacja kierunku i znaczenia poprawna; ograniczenie niepełne. |
| 2 | Interpretacja własna, zgodna z wynikiem, bez utożsamienia istotności z wagą praktyczną. |
