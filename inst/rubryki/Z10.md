# Rubryka Z10

Wersja 1.0.0 — rocznik 2026-27

Maksimum: 10 punktów. Wagi w ocenie tej części kursu i terminy określa konfiguracja rocznika.

Kontrola techniczna sprawdza pliki i odtworzenie; dobór, interpretację i uzasadnienie ocenia osoba prowadząca. Brak istotności nie obniża punktacji.

## Z10.1 — 3 pkt

Skrypt wykonuje się od surowych danych do wskazanych wyników w świeżej sesji.

| Punkty | Obserwowalny dowód |
|---:|---|
| 0 | Brak dowodu lub wynik nie realizuje kryterium. |
| 0.75 | Kod wymaga ręcznego przygotowania obiektów. |
| 1.5 | Kod działa częściowo; jeden etap lub ścieżka zależy od poprzedniej sesji. |
| 2.25 | Cały kod działa w świeżej sesji; instrukcja wykonania niepełna. |
| 3 | Skrypt wykonuje się od surowych danych do wskazanych wyników w świeżej sesji. |

| Punkty | Obserwowalny dowód |
