# Rubryka Z02

Wersja 1.0.0 — rocznik 2026-27

Maksimum: 10 punktów. Wagi w ocenie tej części kursu i terminy określa konfiguracja rocznika.

Kontrola techniczna sprawdza pliki i odtworzenie; dobór, interpretację i uzasadnienie ocenia osoba prowadząca. Brak istotności nie obniża punktacji.

## Z02.1 — 2 pkt

Poprawny import: separator, polskie znaki, liczba wierszy/kolumn i kontrola struktury.

| Punkty | Obserwowalny dowód |
|---:|---|
| 0 | Brak dowodu lub wynik nie realizuje kryterium. |
| 0.5 | Plik odczytany, lecz separator rozdziela dane błędnie. |
| 1 | Poprawne kolumny, ale pominięte kodowanie lub kontrola N. |
| 1.5 | Import i N poprawne; jedna kontrola struktury pominięta. |
| 2 | Poprawny import: separator, polskie znaki, liczba wierszy/kolumn i kontrola struktury. |

## Z02.2 — 4 pkt

Poprawnie odczytano działanie gotowych reguł dla typów, kodów braków i duplikatów.

| Punkty | Obserwowalny dowód |
|---:|---|
| 0 | Brak dowodu lub wynik nie realizuje kryterium. |
| 1 | Opis reguł prowadzi do nieuzasadnionej utraty odpowiedzi. |
| 2 | Dwie z trzech reguł odczytano poprawnie; typ, brak albo duplikat nadal mylony. |
| 3 | Wszystkie reguły odczytano poprawnie; drobna luka uzasadnienia. |
| 4 | Poprawnie odczytano działanie gotowych reguł dla typów, kodów braków i duplikatów. |

## Z02.3 — 2 pkt

Dziennik pokazuje reguły, N przed/po, różnicę między brakiem a zerem.

| Punkty | Obserwowalny dowód |
|---:|---|
| 0 | Brak dowodu lub wynik nie realizuje kryterium. |
| 0.5 | Wymieniono zmianę bez reguły i liczby wierszy. |
| 1 | N przed/po poprawne, lecz brak mylony z zerem. |
| 1.5 | Reguły i rozróżnienie brak/zero poprawne; jedna liczba pominięta. |
| 2 | Dziennik pokazuje reguły, N przed/po, różnicę między brakiem a zerem. |

## Z02.4 — 2 pkt

Gotowy skrypt odtwarza czyszczenie od surowego pliku, a zapisany CSV zgadza się z dziennikiem.

| Punkty | Obserwowalny dowód |
|---:|---|
| 0 | Brak dowodu lub wynik nie realizuje kryterium. |
| 0.5 | Wynik zależy od ręcznej zmiany surowych danych. |
| 1 | Skrypt działa, ale eksport nie zgadza się z jedną regułą lub dziennikiem. |
| 1.5 | Odtwarzalny CSV i dziennik są zgodne; pominięto instrukcję wykonania. |
| 2 | Gotowy skrypt odtwarza czyszczenie od surowego pliku, a zapisany CSV zgadza się z dziennikiem. |
