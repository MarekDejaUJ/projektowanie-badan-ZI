# Rubryka Z05

Wersja 1.1.0 — rocznik 2026-27

Maksimum: 10 punktów. Wagi i terminy określa konfiguracja rocznika.

Kontrola techniczna sprawdza pliki i odtworzenie; dobór, interpretację i uzasadnienie ocenia osoba prowadząca. Brak istotności nie obniża punktacji. Nie wymaga się napisania własnego programu analiz ani osiągnięcia limitu słów.

Dowodem jest pięć odpowiedzi CHALLENGE (S01–S05) wpisanych poza chunkami do tego samego Rmd, jego wyniki i zgodny PDF. Pola przypisane do kryterium wskazują, gdzie szukać dowodu; nie są dodatkowymi zadaniami. LEARN dostarcza przykładów i nie wymaga kolejnych odpowiedzi do oceny.

## Z05.1 — 3 pkt

Estymanda, estymata, SE i właściwie nazwany przedział.

Dowód: S01 podaje estymandę, N osób i indeksów, średnią, SD, SE i różnicę od 3, objaśniając wzór SE. S02 odczytuje oba 95% CI średniej oraz klasyczny CI różnicy; nie myli przedziału parametru z zakresem 95% indywidualnych wyników.

Pola odpowiedzi: S01, S02

| Punkty | Obserwowalny dowód |
|--------:|---------------------------------------------------------------|
| 0 | Brak dowodu albo opis sprzeczny z istotą kryterium. |
| 0.75 | Podano estymatę bez właściwego N lub nazwy parametru. |
| 1.5 | Estymata jest poprawna, ale SE pomylono z SD lub przedział średniej z przedziałem różnicy albo osób. |
| 2.25 | Estymanda, liczby i sens przedziałów są poprawne; pominięto jeden symbol, jednostkę lub poziom ufności. |
| 3 | S01 podaje estymandę, N osób i indeksów, średnią, SD, SE i różnicę od 3, objaśniając wzór SE. S02 odczytuje oba 95% CI średniej oraz klasyczny CI różnicy; nie myli przedziału parametru z zakresem 95% indywidualnych wyników. |

Pola odpowiedzi: S03, S05

| Punkty | Obserwowalny dowód |
|--------:|---------------------------------------------------------------|
| 0 | Brak dowodu albo opis sprzeczny z istotą kryterium. |
| 0.75 | Podano tylko p lub etykietę istotności, bez hipotezy i statystyki. |
| 1.5 | Oba wyniki są obecne, ale błędnie objaśniono p, df, regułę skrajności lub założenie zmiany znaków. |
| 2.25 | Statystyki, oba p i ich sens są poprawne; jedno objaśnienie warunku lub wyniku przy progu jest niepełne. |
| 3 | S03 podaje H0, t, df, p klasyczne, obserwowane T, B i p_MC oraz dwustronną regułę skrajności. Wyjaśnia p warunkowo względem H0 i modelu oraz wymaganą symetrię odchyleń przy zmianie znaków. S05 nie pomija różnicy wyników przy granicy 0,05. |
