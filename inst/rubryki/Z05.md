# Rubryka Z05

Wersja 1.0.0 — rocznik 2026-27

Maksimum: 10 punktów. Wagi w ocenie tej części kursu i terminy określa konfiguracja rocznika.

Kontrola techniczna sprawdza pliki i odtworzenie; dobór, interpretację i uzasadnienie ocenia osoba prowadząca. Brak istotności nie obniża punktacji.

## Z05.1 — 3 pkt

Estymata i przedział dla wskazanej zmiennej są poprawne, z właściwym N.

| Punkty | Obserwowalny dowód |
|---:|---|
| 0 | Brak dowodu lub wynik nie realizuje kryterium. |
| 0.75 | Estymata bez poprawnego N lub przedziału. |
| 1.5 | Estymata poprawna; błędny błąd standardowy albo granica przedziału. |
| 2.25 | Estymata, N i granice poprawne; pominięty poziom ufności. |
| 3 | Estymata i przedział dla wskazanej zmiennej są poprawne, z właściwym N. |

## Z05.2 — 2 pkt

Poprawnie odczytano bootstrap średniej i permutacyjną zmianę znaków, wraz z B i ich odmiennym celem.

| Punkty | Obserwowalny dowód |
|---:|---|
| 0 | Brak dowodu lub wynik nie realizuje kryterium. |
| 0.5 | Pomylono bootstrap z permutacją albo poziom losowania. |
| 1 | Oba wyniki odnaleziono, lecz pomylono ich cel lub pominięto B. |
| 1.5 | Bootstrap, zmiana znaków i B są poprawne; jedno wyjaśnienie procedury jest niepełne. |
| 2 | Poprawnie odczytano bootstrap średniej i permutacyjną zmianę znaków, wraz z B i ich odmiennym celem. |

## Z05.3 — 3 pkt

Wynik klasyczny i permutacyjny zawiera N, efekt, CI, t, df, p oraz p_perm i jest poprawnie objaśniony.

| Punkty | Obserwowalny dowód |
|---:|---|
| 0 | Brak dowodu lub wynik nie realizuje kryterium. |
| 0.75 | Podano tylko jedno p bez N, efektu i przedziału. |
| 1.5 | Oba tory są obecne, lecz statystyka, df albo znaczenie p jest błędne. |
| 2.25 | Kompletny odczyt obu torów; jedno objaśnienie niepewności jest niepełne. |
| 3 | Wynik klasyczny i permutacyjny zawiera N, efekt, CI, t, df, p oraz p_perm i jest poprawnie objaśniony. |

## Z05.4 — 2 pkt

Wniosek odróżnia precyzję od znaczenia praktycznego i wskazuje ograniczenie próby.

| Punkty | Obserwowalny dowód |
|---:|---|
| 0 | Brak dowodu lub wynik nie realizuje kryterium. |
| 0.5 | Wniosek powtarza estymatę bez oceny precyzji. |
| 1 | Precyzja opisana; pominięte ograniczenie lub znaczenie praktyczne. |
| 1.5 | Precyzja, znaczenie i ograniczenie poprawne; niewielka luka uzasadnienia. |
| 2 | Wniosek odróżnia precyzję od znaczenia praktycznego i wskazuje ograniczenie próby. |
