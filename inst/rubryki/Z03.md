# Rubryka Z03

Wersja 1.0.0 — rocznik 2026-27

Maksimum: 10 punktów. Wagi w ocenie tej części kursu i terminy określa konfiguracja rocznika.

Kontrola techniczna sprawdza pliki i odtworzenie; dobór, interpretację i uzasadnienie ocenia osoba prowadząca. Brak istotności nie obniża punktacji.

## Z03.1 — 3 pkt

Z gotowego opisu poprawnie odczytano N, braki oraz miary położenia i zróżnicowania.

| Punkty | Obserwowalny dowód |
|---:|---|
| 0 | Brak dowodu lub wynik nie realizuje kryterium. |
| 0.75 | Odczytano jedną miarę, lecz pomylono N lub braki. |
| 1.5 | Miary położenia są poprawne; miara zróżnicowania albo N jest błędne. |
| 2.25 | Odczyt liczb jest poprawny; jedna jednostka została pominięta. |
| 3 | Z gotowego opisu poprawnie odczytano N, braki oraz miary położenia i zróżnicowania. |

## Z03.2 — 3 pkt

Dwa gotowe wykresy poprawnie odczytano, z uwzględnieniem osi, jednostek i kształtu rozkładu.

| Punkty | Obserwowalny dowód |
|---:|---|
| 0 | Brak dowodu lub wynik nie realizuje kryterium. |
| 0.75 | Nazwano jeden wykres bez odczytu osi lub jednostki. |
| 1.5 | Dwa wykresy opisano, lecz jeden wniosek nie odpowiada widocznemu rozkładowi. |
| 2.25 | Oba wykresy odczytano poprawnie; brakuje jednej etykiety lub różnicy między nimi. |
| 3 | Dwa gotowe wykresy poprawnie odczytano, z uwzględnieniem osi, jednostek i kształtu rozkładu. |

## Z03.3 — 2 pkt

Uzasadnienie wyboru średniej/mediany lub częstości uwzględnia typ i asymetrię.

| Punkty | Obserwowalny dowód |
|---:|---|
| 0 | Brak dowodu lub wynik nie realizuje kryterium. |
| 0.5 | Wymieniono średnią lub medianę bez argumentu. |
| 1 | Argument opiera się na skali, lecz pomija asymetrię widoczną w danych. |
| 1.5 | Wybór uzasadniony skalą i asymetrią; brakuje odniesienia do jednej liczby. |
| 2 | Uzasadnienie wyboru średniej/mediany lub częstości uwzględnia typ i asymetrię. |

## Z03.4 — 2 pkt

Własny opis danych odnosi się do liczb, bez wniosków wykraczających poza próbę.

| Punkty | Obserwowalny dowód |
|---:|---|
| 0 | Brak dowodu lub wynik nie realizuje kryterium. |
| 0.5 | Opis ogólny bez liczb. |
| 1 | Opis częściowo zgodny z liczbami, lecz uogólnia na populację. |
| 1.5 | Własny opis liczbowy w granicach próby; jedno pominięcie zakresu. |
| 2 | Własny opis danych odnosi się do liczb, bez wniosków wykraczających poza próbę. |
