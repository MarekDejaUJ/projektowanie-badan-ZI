# Rubryka Z08

Wersja 1.0.0 — rocznik 2026-27

Maksimum: 10 punktów. Wagi w ocenie tej części kursu i terminy określa konfiguracja rocznika.

Kontrola techniczna sprawdza pliki i odtworzenie; dobór, interpretację i uzasadnienie ocenia osoba prowadząca. Brak istotności nie obniża punktacji.

## Z08.1 — 3 pkt

Dobór Pearsona/Spearmana i wykres uwzględnia skale i charakter związku.

| Punkty | Obserwowalny dowód |
|---:|---|
| 0 | Brak dowodu lub wynik nie realizuje kryterium. |
| 0.75 | Współczynnik wybrano bez sprawdzenia skal lub wykresu. |
| 1.5 | Skale opisane, ale wybór nie pasuje do widocznego związku. |
| 2.25 | Właściwy wybór i wykres; jedno uzasadnienie pominięte. |
| 3 | Dobór Pearsona/Spearmana i wykres uwzględnia skale i charakter związku. |

## Z08.2 — 2 pkt

Współczynnik, N par, przedział, p klasyczne i p_perm odczytano poprawnie; bez fikcyjnych df.

| Punkty | Obserwowalny dowód |
|---:|---|
| 0 | Brak dowodu lub wynik nie realizuje kryterium. |
| 0.5 | Podano współczynnik bez poprawnej liczby par. |
| 1 | Współczynnik i jedno p są poprawne; brakuje drugiego toru albo przedziału. |
| 1.5 | Oba tory i przedział są poprawne; pominięto B albo jedną granicę. |
| 2 | Współczynnik, N par, przedział, p klasyczne i p_perm odczytano poprawnie; bez fikcyjnych df. |

## Z08.3 — 3 pkt

Student czyta nachylenie, jednostki, R² i podstawowy sygnał diagnostyczny prostej regresji.

| Punkty | Obserwowalny dowód |
|---:|---|
| 0 | Brak dowodu lub wynik nie realizuje kryterium. |
| 0.75 | Odczytano nazwę współczynnika bez sensu nachylenia. |
| 1.5 | Nachylenie częściowo poprawne; jednostki, R² albo diagnostyka błędne. |
| 2.25 | Nachylenie, jednostki i R² poprawne; opis diagnostyczny niepełny. |
| 3 | Student czyta nachylenie, jednostki, R² i podstawowy sygnał diagnostyczny prostej regresji. |

## Z08.4 — 2 pkt

Interpretacja odróżnia związek, przewidywanie i przyczynowość oraz wskazuje ograniczenie.

| Punkty | Obserwowalny dowód |
|---:|---|

| 0.5 | Wniosek powtarza współczynnik bez interpretacji. |
| 1 | Związek opisano, lecz przewidywanie utożsamiono z przyczyną. |

| 2 | Interpretacja odróżnia związek, przewidywanie i przyczynowość oraz wskazuje ograniczenie. |
