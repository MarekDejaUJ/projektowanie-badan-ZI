# Rubryka Z01

Wersja 1.1.0 — rocznik 2026-27

Maksimum: 10 punktów. Wagi i terminy określa konfiguracja rocznika.

Kontrola techniczna sprawdza pliki i odtworzenie; dobór, interpretację i uzasadnienie ocenia osoba prowadząca. Brak istotności nie obniża punktacji. Nie wymaga się napisania własnego programu analiz ani osiągnięcia limitu słów.

Dowodem jest pięć odpowiedzi CHALLENGE (S01–S05) wpisanych poza chunkami do tego samego Rmd, jego wyniki i zgodny PDF. Pola przypisane do kryterium wskazują, gdzie szukać dowodu; nie są dodatkowymi zadaniami. LEARN dostarcza przykładów i nie wymaga kolejnych odpowiedzi do oceny.

## Z01.1 — 3 pkt

Odtwarzalna praca w jednym Rmd.

Dowód: Zapisany Rmd i odpowiadający mu PDF zawierają wyniki gotowych chunków oraz pięć własnych odpowiedzi S01–S05 poza kodem; analiza.R odtwarza wyniki od początku. Nie wymaga się własnego programu.

Pola odpowiedzi: S01, S02, S03, S04, S05

| Punkty | Obserwowalny dowód |
|--------:|---------------------------------------------------------------|
| 0 | Brak dowodu albo opis sprzeczny z istotą kryterium. |
| 0.75 | Uruchomiono fragment, lecz nie zachowano wyników i odpowiedzi w roboczym Rmd. |
| 1.5 | Część wyników jest odtwarzalna, ale PDF pomija odpowiedzi lub nie odpowiada zapisanej wersji. |
| 2.25 | Wyniki i pięć odpowiedzi odtwarzają się; drobna usterka prezentacji nie zmienia ich sensu. |
| 3 | Zapisany Rmd i odpowiadający mu PDF zawierają wyniki gotowych chunków oraz pięć własnych odpowiedzi S01–S05 poza kodem; analiza.R odtwarza wyniki od początku. Nie wymaga się własnego programu. |

## Z01.2 — 3 pkt

Odczyt rekordu, miar czasu i mianownika odsetka.

Dowód: S01–S04: poprawny odczyt rekordu p06 i dwóch adresów wartości, N osób i ważnych czasów, średniej, mediany oraz liczby i odsetka sukcesów. Jednostki i mianowniki są jawne; NA nie zastąpiono zerem.

Pola odpowiedzi: S01, S02, S03, S04

| Punkty | Obserwowalny dowód |
|--------:|---------------------------------------------------------------|
| 0 | Brak dowodu albo opis sprzeczny z istotą kryterium. |
| 0.75 | Odczytano pojedynczą liczbę bez właściwego rekordu lub mianownika. |
| 1.5 | Większość liczb jest poprawna, ale pomylono ważne N, jednostkę lub wpływ zastąpienia braku zerem. |
| 2.25 | Odczyt i porównanie reguł są poprawne; pominięto jedną jednostkę lub jedną żądaną liczbę. |
| 3 | S01–S04: poprawny odczyt rekordu p06 i dwóch adresów wartości, N osób i ważnych czasów, średniej, mediany oraz liczby i odsetka sukcesów. Jednostki i mianowniki są jawne; NA nie zastąpiono zerem. |

## Z01.3 — 2 pkt

Źródło wyniku i granice wniosku o zachowaniu.

Dowód: S02 odróżnia kod w chunku, wynik i tekst interpretacji. S03 wskazuje brakującą informację o p04. S05 porównuje dwa konkretne rekordy, rozdziela pewność, czas i poprawność oraz proponuje dodatkowy pomiar bez diagnozowania ogólnych kompetencji.

Pola odpowiedzi: S02, S03, S05

| Punkty | Obserwowalny dowód |
|--------:|---------------------------------------------------------------|
| 0 | Brak dowodu albo opis sprzeczny z istotą kryterium. |
| 0.5 | Nazwano kod lub deklarację bez wskazania źródła i znaczenia wyniku. |
| 1 | Rozdzielono kod od tekstu, lecz wniosek o pewności i wykonaniu nie jest poparty dwoma rekordami lub uogólnia na całe kompetencje. |
| 1.5 | Poprawne źródło i ostrożny wniosek z rekordów; jedno doprecyzowanie protokołu albo dodatkowego pomiaru jest niepełne. |
| 2 | S02 odróżnia kod w chunku, wynik i tekst interpretacji. S03 wskazuje brakującą informację o p04. S05 porównuje dwa konkretne rekordy, rozdziela pewność, czas i poprawność oraz proponuje dodatkowy pomiar bez diagnozowania ogólnych kompetencji. |

## Z01.4 — 2 pkt

Własne ID, pliki i potwierdzona oddana wersja.

Dowód: Metadane Rmd/PDF i prywatnego repozytorium odpowiadają własnemu ID. Pokwitowanie wysyłki wskazuje zdalne SHA oraz status odbioru. Nie trzeba dopisywać SHA do Rmd ani tworzyć szóstej odpowiedzi; ocenia się zapisane pliki i pokwitowanie.

Pola odpowiedzi: S01, S02, S03, S04, S05

| Punkty | Obserwowalny dowód |
|--------:|---------------------------------------------------------------|
| 0 | Brak dowodu albo opis sprzeczny z istotą kryterium. |
| 0.5 | Pliki istnieją, lecz nie można powiązać ich z właściwym ID i repozytorium. |
| 1 | Własne ID i pliki są zgodne, ale dostępny jest tylko lokalny zapis lub commit, bez potwierdzenia odbioru. |
| 1.5 | Odbiór i ID są potwierdzone; pozostała drobna niespójność oznaczenia wersji pliku. |
| 2 | Metadane Rmd/PDF i prywatnego repozytorium odpowiadają własnemu ID. Pokwitowanie wysyłki wskazuje zdalne SHA oraz status odbioru. Nie trzeba dopisywać SHA do Rmd ani tworzyć szóstej odpowiedzi; ocenia się zapisane pliki i pokwitowanie. |
