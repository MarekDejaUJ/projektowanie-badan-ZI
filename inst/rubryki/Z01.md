# Rubryka Z01

Wersja 1.0.0 — rocznik 2026-27

Maksimum: 10 punktów. Wagi w ocenie tej części kursu i terminy określa konfiguracja rocznika.

Kontrola techniczna sprawdza pliki i odtworzenie; dobór, interpretację i uzasadnienie ocenia osoba prowadząca. Brak istotności nie obniża punktacji.

## Z01.1 — 3 pkt

Gotowy skrypt uruchomiono od początku; zapisany wynik potwierdza właściwy projekt i dane.

| Punkty | Obserwowalny dowód |
|---:|---|
| 0 | Brak dowodu lub wynik nie realizuje kryterium. |
| 0.75 | Uruchomiono fragment bez zapisanego wyniku. |
| 1.5 | Powstał wynik, lecz nie odpowiada własnemu projektowi albo danym. |
| 2.25 | Gotowy skrypt i wynik są poprawne; pominięto jedno potwierdzenie projektu. |
| 3 | Gotowy skrypt uruchomiono od początku; zapisany wynik potwierdza właściwy projekt i dane. |

## Z01.2 — 3 pkt

Z gotowego wyniku poprawnie odczytano wiersz, kolumnę, wartość, jednostkę i N.

| Punkty | Obserwowalny dowód |
|---:|---|
| 0 | Brak dowodu lub wynik nie realizuje kryterium. |
| 0.75 | Wskazano tabelę bez poprawnego odczytu wartości. |
| 1.5 | Odczytano wartość, lecz pomylono jednostkę albo N. |
| 2.25 | Odczyt jest poprawny; jeden element źródła wyniku pominięto. |
| 3 | Z gotowego wyniku poprawnie odczytano wiersz, kolumnę, wartość, jednostkę i N. |

## Z01.3 — 2 pkt

W `.md` poprawnie objaśniono konsolę, skrypt i źródło jednego wyniku.

| Punkty | Obserwowalny dowód |
|---:|---|
| 0 | Brak dowodu lub wynik nie realizuje kryterium. |
| 0.5 | Nazwano konsolę lub skrypt bez wyjaśnienia roli. |
| 1 | Role wyjaśniono, lecz nie wskazano źródła wyniku. |
| 1.5 | Role i źródło wyniku poprawne; opis pomija sposób ponownego wykonania. |
| 2 | W `.md` poprawnie objaśniono konsolę, skrypt i źródło jednego wyniku. |

## Z01.4 — 2 pkt

| Punkty | Obserwowalny dowód |
|---:|---|
| 0 | Brak dowodu lub wynik nie realizuje kryterium. |
| 0.5 | Pliki przygotowane, lecz brak zgodności repo/ID. |
| 1 | Własne repo/ID, lecz wskazano tylko lokalny commit. |
| 1.5 | Potwierdzone zdalne SHA; opis statusu niepełny. |
| 2 | Wyniki i pliki należą do własnego repo/ID; student potrafi wskazać potwierdzone SHA oraz status. |
